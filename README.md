## `11 / PRINCÍPIOS DE TRABALHO`

</div>

<table align="center" width="100%">
<tr>
<td width="50%" valign="top">

**Rigor intelectual**  
Antes de concluir, procuro compreender as evidências e distinguir hipótese de fato.

**Simplicidade**  
Uma solução clara e sustentável merece preferência diante de uma solução desnecessariamente complexa.

**Responsabilidade**  
Erros fazem parte do desenvolvimento; ignorá-los, não. Investigar a causa é parte essencial do trabalho.

</td>
<td width="50%" valign="top">

**Documentação**  
Conhecimento que pode ser consultado, reproduzido e aprimorado possui valor duradouro.

**Aprendizado contínuo**  
Cada projeto deve proporcionar uma compreensão superior àquela existente antes de sua realização.

**Evolução**  
A qualidade não é um ponto de chegada, mas um padrão que deve ser progressivamente elevado.

</td>
</tr>
</table>

<div align="center">

> **Meu propósito é construir uma trajetória técnica que seja reconhecida não pela quantidade de promessas, mas pela qualidade daquilo que efetivamente for desenvolvido.**
